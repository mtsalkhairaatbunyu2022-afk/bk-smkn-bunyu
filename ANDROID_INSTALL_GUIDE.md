# Panduan Instalasi Aplikasi pada HP Android

Aplikasi **BK SMK NEGERI 1 BUNYU** dibuat dengan teknologi Progressive Web App (PWA) tingkat lanjut. Setelah diinstal, aplikasi akan berjalan penuh seperti aplikasi native Android dengan logo resmi Konselor di Home Screen Anda.

---

## Cara 1: Menggunakan Tombol INSTALL APP di Dalam Aplikasi (Paling Praktis)

1. Buka aplikasi **BK SMK NEGERI 1 BUNYU** di browser HP Android Anda (seperti Google Chrome atau Brave).
2. Di halaman utama (Landing Page), ketuk tombol **INSTALL APP**.
3. Jendela konfirmasi Android akan muncul: *"Install BK SMKN 1 Bunyu?"*
4. Ketuk **Install**.
5. Tunggu 2-5 detik. Ikon logo **Konselor** resmi akan muncul di **Home Screen** dan **Daftar Aplikasi (App Drawer)** HP Android Anda!

---

## Cara 2: Instalasi Manual via Menu Google Chrome Android

Jika prompt instalasi otomatis tidak muncul:

1. Buka situs aplikasi di Google Chrome Android.
2. Ketuk ikon **Titik Tiga (⋮)** di pojok kanan atas browser.
3. Gulir ke bawah dan ketuk opsi **Tambahkan ke Layar Utama** (atau **Instal Aplikasi**).
4. Masukkan nama aplikasi (default: *BK SMK NEGERI 1 BUNYU*) lalu ketuk **Tambah**.
5. Aplikasi kini siap digunakan offline tanpa kuota internet!

---

## Keunggulan Aplikasi Setelah Diinstal di Android:

- **Standalone Mode**: Berjalan penuh tanpa baris URL/alamat browser.
- **Offline Total**: Seluruh data siswa, absensi, jurnal, dan konseling tersimpan secara lokal di HP Anda.
- **Icon Resmi**: Menggunakan logo Konselor beresolusi tinggi dengan dukungan Adaptive Icon & Maskable Icon Android.
- **Splash Screen Native**: Menampilkan layar pembuka biru tua dengan animasi khas saat aplikasi dibuka.
