# Panduan Instalasi Aplikasi pada Laptop / PC Windows

Aplikasi **BK SMK NEGERI 1 BUNYU** dapat diinstal di komputer/laptop Windows 10 & Windows 11 sebagai aplikasi desktop standalone dengan ikon logo Konselor di **Desktop** dan **Start Menu** Windows.

---

## Cara 1: Menggunakan Google Chrome / Microsoft Edge di Windows

1. Buka browser **Google Chrome** atau **Microsoft Edge** di Windows Anda.
2. Akses alamat web aplikasi.
3. Di halaman utama aplikasi, klik tombol **INSTALL APP**.
4. Atau perhatikan bagian kanan atas browser (Address Bar / Bilah Alamat):
   - Di Google Chrome: Klik ikon **Komputer + Panah Bawah** (Instal).
   - Di Microsoft Edge: Klik ikon **Tiga Kotak + Plus** (App Available) atau ikon titik tiga (⋯) → **Apps** → **Install BK SMKN 1 Bunyu**.
5. Klik tombol **Install** pada dialog konfirmasi.

---

## Hasil Instalasi di Windows:

- **Shortcut Desktop**: Ikon logo Konselor resmi akan otomatis muncul di Desktop Windows.
- **Start Menu**: Aplikasi terdaftar di Start Menu Windows dengan nama `BK SMK NEGERI 1 BUNYU`.
- **Pin to Taskbar**: Anda dapat melakukan klik kanan pada jendela aplikasi dan memilih **Pin to Taskbar** agar mudah diakses sekali klik.
- **Tampilan Jendela Khusus**: Aplikasi terbuka dalam jendela mandiri (Standalone Window) tanpa tab browser.

---

## Penggunaan Saat Komputer Offline (Tanpa Internet)

Aplikasi akan tetap berfungsi 100% normal tanpa jaringan internet:
- Membuka data siswa, absensi, jurnal, dan konseling.
- Menginput layanan bimbingan konseling dan mencetak kartu PDF.
- Melakukan Backup & Restore database JSON secara lokal.
